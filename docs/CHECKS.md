# Проверка перед передачей

Проверены обе языковые версии в Chromium по пути `/CallR/` при ширинах экрана:

`320, 360, 390, 430, 760, 761, 768, 820, 1024, 1280, 1440, 1920 px`.

Проверены отсутствие горизонтальной прокрутки, загрузка изображений, локальные файлы и ссылки на разделы. Проверены все шесть сценариев, переходы вперёд и назад, клавиши стрелок и End, мобильное меню и закрытие Escape, раскрытие критериев и FAQ. Английский PDF возвращает HTTP 200. Консоль браузера не показала ошибок при обычной загрузке.

QR-код декодирован: `https://t.me/SQflex`. В архиве нет отдельных файлов шрифтов, сторонних JavaScript-пакетов, ключей API и исходников продукта.

Без JavaScript основное содержание остаётся доступным, все сценарии отображаются последовательно. Управление анимацией учитывает системное уменьшение движения.

Браузерная проверка выполнена локально на HTML/CSS/JS и ресурсах сайта. Это не проверка уже опубликованного GitHub Pages или DNS домена: публикация и привязка домена выполняются отдельно.
