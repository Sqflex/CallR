# CallR — готовый сайт для GitHub Pages

Русская и английская версии сайта CallR. Светлая палитра презентации, фирменный объёмный знак, три модуля продукта, настройка методологии, шесть сценариев применения, презентации в PDF и контакты.

**Сайт готов к публикации. Сборка, npm, сервер приложения и ключи API не нужны.**

## Посмотреть на компьютере

Распакуйте архив и откройте `index.html` в браузере. Английская версия — `en.html`. Файлы должны оставаться рядом с папкой `assets`.

Для проверки через локальный сервер, если установлен Python:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Команду нужно запускать в папке с `index.html`. Чтобы проверить путь GitHub Pages, запустите сервер из родительской папки и откройте `http://localhost:8000/CallR/`.

## Опубликовать на GitHub Pages

1. Сайт хранится в публичном репозитории [Sqflex/CallR](https://github.com/Sqflex/CallR), в ветке `main`. Файл `index.html` находится в корне рядом с `CNAME`, `.nojekyll`, `en.html` и папкой `assets`.
2. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
3. В **Settings → Pages → Custom domain** должен быть указан `callr.online`. После настройки DNS проверьте обе языковые версии и PDF по адресам ниже.

Основной адрес сайта:

```text
https://callr.online/
https://callr.online/en.html
https://callr.online/assets/CallR_Pitch_RU.pdf
```

Все локальные ссылки сделаны относительными: сайт работает и в подпапке репозитория, и на собственном домене. Скрытый файл `.nojekyll` должен попасть в репозиторий вместе с остальными файлами. Для этой статической сборки GitHub Actions workflow не нужен.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Подключить callr.online

Пошаговая инструкция и DNS-записи находятся в `docs/DOMAIN.md`.

В корне репозитория лежит `CNAME` со строкой `callr.online`. Записи DNS и проверка HTTPS описаны в `docs/DOMAIN.md`.

Canonical, Open Graph, robots.txt и sitemap настроены на `https://callr.online/`.

## Что работает

Переключение RU/EN, мобильное меню, клавиатурная навигация по сценариям, переключатели «вперёд/назад», раскрытие критериев и ответов на вопросы, переходы к разделам, открытие PDF, Telegram и звонок по номеру. Кнопка копирования телефона использует Clipboard API; при недоступности буфера показывает номер, а не ложное сообщение об успешном копировании.

На сайте **нет формы сбора заявок, внешней аналитики, cookies, записи с микрофона или передачи аудио**. Кнопки демонстрации ведут к контактам, а затем в Telegram. Это сайт продукта, не интерфейс самой системы CallR. Код агентов и клиентские данные не публикуются.

Клиентских JavaScript-библиотек и внешних CDN нет. Оформление использует системный стек шрифтов с Inter при наличии; отдельные файлы шрифтов не входят в архив. Сам логотип переведён в векторные контуры и не зависит от установленных шрифтов.
